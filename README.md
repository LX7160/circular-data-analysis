# Circular Data and Statistical Methods
This is an introduction to circular data and statistical methods, with a planned application to biological data.

## Overview
The project explores how circular data differs from ordinary linear data and introduces statistical methods for analyzing circular observations. This provides a foundation for a planned future analysis of biological data using the methods discussed.

## Current Status
The current report focuses on concepts and an introduction to statistical methods for circular data. The biological data analysis is not yet complete and will be added in future updates.
